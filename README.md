# E-Commerce-Sales-PowerBI-Dashboard
An interactive Power BI dashboard developed to analyze sales, profit trends, and customer segments for an e-commerce supermarket.

## 💡 Key Business Insights
* **Regional Dynamics:** South region leads in Average Sales, while the West region generates the highest overall Profit.
* **Product Profitability:** Technology products are the highest profit driver, whereas Furniture shows low margins.
* **Customer Segments:** The Consumer segment dominates, contributing over 50.5% of total sales.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** For Data Visualization and Dashboard design.
* **Excel / CSV:** Data source containing transactional records.
